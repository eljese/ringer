- `ringer.py` retains `claude`, `agy`, and `opencode` install hints in `ENGINE_INSTALL_HINTS`.
- `ringer.py` retains the Codex CLI plugin installer helpers (`codex_root`, `codex_plugin_source`, etc.).
- `engines/agy-ringer.sh`, `plugins/ringer/`, `docs/AGY.md`, `docs/CLAUDE-CODE.md`, and the fork-only test files (`tests/test_agy_ringer.py`, `tests/test_claude_engine.py`, `tests/test_install_agent_codex.py`) are present.
- `docs/MODEL-NOTES.md` retains the agy/Gemini evidence section.

Following upstream's fast-forward would delete all of that.
